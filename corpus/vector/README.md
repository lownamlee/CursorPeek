# Generated vector corpus

This corpus is generated by `src/worker/vector/corpus.rs`. Every document is an original SVG
literal written for the test; no third-party artwork is committed.

`cases.tsv` is the reviewable inventory. Each row names the generated document class, whether it
renders as a still or animated preview or falls back to inert source text with a named refusal
reason, and whether the resulting BGRA frames are replayed through the Direct2D preview window.

The corpus covers:

- every rendered shape, plus transforms, groups, `use`/`symbol`, and nested viewports;
- solid, gradient, and inherited paint, the CSS cascade, and dashed strokes;
- SMIL attribute, transform, and `set` animation;
- script, event-handler, embedded-image, external-reference, and entity-declaration refusals;
- malformed markup and path data, a non-SVG root, and a document that paints nothing;
- non-UTF-8 encoding, the source-size cap, and a recursive `use` chain.

Refused documents are not failures: each one must fall back to the inert text preview, which is
what the `fallback:<reason>` expectation records.
